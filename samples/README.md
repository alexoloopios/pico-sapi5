# Samples

Rendered straight from the engine so the voices can be heard without building or
installing anything. All are 16 kHz 16-bit mono WAV, which is what Pico produces.

Everything here is regenerated by `pico_render`, whose exact invocation is given
against each file. Nothing in this directory is needed to build or run the
engine.

## The six voices

The same sentence in each language, at default rate and pitch.

| File | Voice | Length | Spoken |
| --- | --- | --- | --- |
| `1_en-US.wav` | Pico American English | 4.82 s | "This is the Pico American English voice, speaking through SAPI five." |
| `2_en-GB.wav` | Pico British English | 4.60 s | "This is the Pico British English voice, speaking through SAPI five." |
| `3_de-DE.wav` | Pico German | 4.50 s | "Dies ist die deutsche Pico-Stimme, die über SAPI fünf spricht." |
| `4_es-ES.wav` | Pico Spanish | 5.02 s | "Esta es la voz española de Pico, hablando a través de SAPI cinco." |
| `5_fr-FR.wav` | Pico French | 3.87 s | "Ceci est la voix française de Pico, qui parle via SAPI cinq." |
| `6_it-IT.wav` | Pico Italian | 5.08 s | "Questa è la voce italiana di Pico, che parla tramite SAPI cinque." |

```
pico_render -v en-US -o 1_en-US.wav "This is the Pico American English voice, speaking through SAPI five."
```

## Rate

SAPI's rate runs −10 to +10. Each end is a factor of three on the speaking rate,
so the two files below are the same sentence about three times apart.

| File | Rate | Pico speed | Length | Command |
| --- | --- | --- | --- | --- |
| `7_rate_slow.wav` | −6 | 52 | 5.84 s | `pico_render -v en-US -r -6 -o 7_rate_slow.wav "..."` |
| `8_rate_fast.wav` | +6 | 193 | 2.08 s | `pico_render -v en-US -r 6 -o 8_rate_fast.wav "..."` |

Both speak "The rate can be set from minus ten to plus ten."

## Pitch

SAPI's pitch also runs −10 to +10, an octave either way, which maps exactly onto
Pico's own 50–200 range. Both files are 3.40 s: changing pitch does not change
how long the utterance takes, which is the point of checking it separately from
rate.

| File | Pitch | Pico pitch | Command |
| --- | --- | --- | --- |
| `9_pitch_low.wav` | −8 | 57 | `pico_render -v en-US -p -8 -o 9_pitch_low.wav "..."` |
| `10_pitch_high.wav` | +8 | 174 | `pico_render -v en-US -p 8 -o 10_pitch_high.wav "..."` |

Both speak "The pitch can be set from minus ten to plus ten."
